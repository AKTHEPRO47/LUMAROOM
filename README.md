# LUMA ROOM  
**Unleash Collective Genius: Swag Together, Slay Together**

LUMA ROOM is a real-time, AI-powered creative platform where users collaborate to write stories, co-watch media, and build tools inside persistent 3D rooms. It transforms digital creation into a shared, immersive experience powered by collective intelligence and generative AI.

![LUMA ROOM Banner](./assets/banner.jpg)

---

## 🚀 Features

- **Shared 3D Rooms** for storytelling, media co-watching, and AI-assisted creation  
- **Multimodal Prompt Composer** that blends voice, text, and emotion into narrative prompts  
- **Watch Mode** with synchronized playback, live reactions, and AI lore commentary  
- **Build Mode** with collaborative code terminals and AI command interfaces  
- **Customizable AI Sidekick** that evolves with the team’s input and skill focus  
- **Real-Time Chat** and presence tracking for transparent, fluid collaboration

## 🧠 What I Learned

- Real-time creative collaboration requires systems that prioritize fluid state, not static logic  
- AI becomes powerful when embedded in a space where people make shared decisions  
- Group creativity thrives with tools that respond to mood, identity, and imagination  
- The best UX for collaboration is one that encourages presence, play, and persistence
